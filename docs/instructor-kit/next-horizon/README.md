# Connected investigations: from evidence to execution

This is an additive teaching sequence for the atlas's expanded working build. The original fabrication, architecture and hall activities remain available in the parent kit. Start from the atlas's Engineering experience selector or the lesson routes below. All computations are bounded teaching specimens; the worksheets record neither completed learner sessions nor physical-device measurements.

Use [the learner worksheet](WORKSHEET.md) before [the instructor key](INSTRUCTOR-KEY.md). [The session plan](SESSION-PLAN.md) identifies prerequisite knowledge and accommodations. [Executable contracts](verify-contracts.mjs) check the numerical answers against the current models and include independent arithmetic at selected boundaries. Run from the repository root with `node --experimental-strip-types docs/instructor-kit/next-horizon/verify-contracts.mjs`.

Preserve a prediction before each intervention. Record the build identity, experience, complete settings, source/model identity and exported record. A correct outcome with an incorrect explanation is different from a wrong prediction revised using evidence. Neither observation alone establishes the platform's learning effectiveness.
