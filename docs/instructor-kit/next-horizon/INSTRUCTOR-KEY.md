- **J1:** Three updates each wait for the slower rank. Changing its extra delay from 0 s to 1 s adds **3 × 1 = 3 s**, not 6 s. Both runs execute six rank gradients and commit three optimizer updates; final weights, optimizer state, RNG, cursor and contribution bytes agree. - **J2:** Before the update-2 replacement becomes authoritative, only update 0 is durable. Losing that live job discards two updates. Reaching update 3 therefore executes **2 lost + 3 retained = 5 updates** and **2 ranks × 5 = 10 rank computations**; four rank computations are rolled back, six support retained updates, and three updates are durable at completion. The replacement write can be partial or complete-but-uncommitted and still leave update 0 authoritative. Restoring full moments, optimizer count, RNG and sampler cursor reproduces the uninterrupted state exactly in this fixture. A weights-only restart does not establish that equivalence. The independent final-test exposure disclosure remains retained.
- **J3:** A recorded seed-7 example on **Node 24.14.0, macOS arm64** produced initial JSON of **28,562 B** and an update-2 replacement of **181,106 B**. Copy-on-write required **209,668 B**, exceeding the 120,000 B case by **89,668 B**; with `rounds:2` and no fault, **209,668 B fit and 209,667 B failed**. These are runtime-specific examples: last-bit floating-point differences can change JSON lengths even with the same seed and model versions. Rerun the verifier, which independently reconstructs checkpoints and reports their sizes and runtime. Old-plus-new bytes must fit; one byte less must fail, preserving the initial durable artifact and both completed live updates. These UTF-8 sizes include instructional owner/replica/trace state; they are not tensor sizes or NCCL wire traffic. Different source checkpoints or dependencies also require recalculating the boundary.
- **M1:** A = [[1,2],[3,4]], B = [[5,6],[7,8]]. The four dot products are **1×5+2×7=19**, **1×6+2×8=22**, **3×5+4×7=43**, **3×6+4×8=50**. Thus C = [[19,22],[43,50]], with eight MACs. Original B[0,0] is little-endian bytes **[5,0,0,0]**. A single data-bit error is corrected; the same C publishes. Two flipped data bits in its low nibble are detected under SECDED and block publication before affected compute. Unchecked extraction turns binary 0101 into 0110, so B[0,0] becomes **6**, bytes **[6,0,0,0]**. Only C's first column changes, by A's first column [1,3]: **[[20,22],[46,50]]**. The original-matrix comparison diagnoses this wrong output; it does not repair it. The code uses eight independent (8,4) words per 32-bit operand, totaling 64 encoded bits; parity storage and ECC logic time are outside this payload/time budget.
- **M2:** Each 3×3 matrix has **9×4=36 real bytes**, rounded to **48 B** for 16-byte allocation alignment. A+B+C require **3×48=144 B**; 96 B is insufficient for every tier choice. Fully staging B adds **48 B source reads** and **48 B destination writes**, but B still occupies its full 48 B destination allocation. There are three 16-byte copies. The assumed startup and copy service give **20+3×8=44 ns** before machine execution. The remote cases preserve actual output and machine-relative commands; each joined command time is its machine time **+44 ns**. The read-tier and host source use the same authored timing, not a measured product comparison. In the two-matrix case, allocations are 16 B each (48 B total) and staging is **20+1×8=28 ns**. Unique payload bytes, allocated bytes and repeated transaction bytes have different denominators.
- **M3:** The default one-axis overlap model gives **100%** at 0 µm, **1%** at 9.9 µm and **0%** at 10 µm. Zero overlap blocks admission, with no staging, memory commands or MACs. Positive overlap changes geometry but supplies no resistance, latency or fault-rate prediction. Removing synthetic qualification is a separate admission failure. On the persistent triple-error fixture, scheduled refresh increases time while leaving the same corrupted operand/output; it does not undo injected bits. Each issued refresh reserves 12 ns, but count only service before the observation horizon: an isolated reservation [20,32) ns viewed at 25 ns has **5 ns observed**, not 12. Three flips can return a correction classification while delivering wrong data; SECDED's one-error correction/two-error detection guarantee applies per 8-bit codeword. There is no spontaneous bit decay, vendor ECC model or device reliability measurement here.

Score each response separately on four dimensions, 0–2 points each: (1) identifies the state and denominator; (2) supplies reproducible numerical/trace evidence; (3) explains the mechanism and a failing alternative; (4) transfers the reasoning while naming a model limit. Keep confidence and assistance separate from correctness. A revised explanation may be stronger evidence of reflection than a lucky initial answer. This rubric has not been validated through observed learner sessions.
