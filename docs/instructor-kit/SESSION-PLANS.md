# Session plans

Learners need familiarity with multiplication, ratios, basic units and the idea of a chip, memory and computer. The core tasks do not require semiconductor process expertise, programming or calculus. Before class, the instructor opens all three Engineering experiences and verifies the scenario contract against the chosen build. Print or distribute the worksheet without the answer key.

## Outcomes

By the end, a learner should be able to:

1. Explain why deposition, exposure, development, etch and inspection change different parts of a specimen or its acceptance record.
2. Calculate a finite mask budget and identify a held-for-review population without treating uncertainty as a physical repair.
3. Verify one matrix output and explain how identical arithmetic can use different scheduling and data movement.
4. Distinguish installed, admitted, commissioned, executed, retained and restart-durable work.
5. Transfer a boundary argument to a new condition while naming an assumption that could change the conclusion.

## Thirty-minute introduction

| Minutes | Activity | Learner evidence |
|---|---|---|
| 0–3 | Orient to the three experiences and synthetic scope. Each learner records one prediction before touching controls. | One prior prediction, retained unedited. |
| 3–11 | Worksheet F1–F2: identify material changes; calculate etch/mask budget; increase uncertainty. | Calculation with nm units and a distinction between geometry and acceptance. |
| 11–19 | Worksheet A1: compute C[0,0], compare scalar and systolic data movement, inspect one accumulator. | Same numeric result with different movement explanation. |
| 19–27 | Worksheet H1–H2: identify admitted racks; lower coolant flow; inspect fault rollback. | A rack-admission calculation and retained-versus-durable distinction. |
| 27–30 | Exit task X1 and one-sentence model limit. | Causal transfer across two boundaries. |

For a mixed group, pair a navigator with an explainer and swap roles at the architecture activity. A projected demonstration plus individual paper responses is an equivalent delivery option. If a participant cannot comfortably manipulate the visualization, use the labeled tables and supplied scenario counts; visual acuity or pointer dexterity is not the learning objective.

## Ninety-minute investigation

| Minutes | Activity | Learner evidence |
|---|---|---|
| 0–10 | Orientation, units and individual predictions. Distinguish a fixed input, a calculated outcome and a source-supported mechanism. | Initial predictions and one declared assumption. |
| 10–30 | F1–F4: stage order, budgets, uncertainty, failure and qualification. Partners predict each change before running it. | Before/after values; explanation of each denominator. |
| 30–50 | A1–A3: same result across four schemes; disabled lanes; a 3 × 3 operation on a 2 × 2 array. | Independent output calculation, traffic counts, tail/fill/drain explanation. |
| 50–70 | H1–H5: electrical/thermal admission, late readiness and checkpoint policy. | Admission calculation and event-specific accounting. |
| 70–80 | H7: hand-checkable commit and restart timeline. | Independent 13-retained-step and energy calculation. |
| 80–87 | X1–X2: choose a proposed improvement and trace its effects and limits across experiences. | Defensible transfer argument with a counterexample. |
| 87–90 | Self-assess using the rubric; keep the initial prediction alongside revised reasoning. | Evidence-based revision, not an erased first answer. |

An instructor may allocate more time to one domain without changing the model contracts. Extra time should deepen explanations or transfer, rather than reward speed at operating the controls. H6, the full-overlap service bound, is an optional extension after learners can state why unlike schedule units or resource rates cannot simply be added into a performance ranking.

## Facilitation and feedback

Ask learners to name the boundary before giving a numerical answer: per die, per wafer, per lot, per package, per issue slot, per wavefront tick, or per retained step. Ask what changed physically, what changed in an acceptance policy, and what changed only in the display. Avoid supplying the result before a learner commits to a prediction.

Use the rubric formatively. A correct number without its denominator receives only partial credit. A wrong first prediction followed by a sound correction is useful evidence of learning activity. It is not evidence that the platform improves learning relative to another method.

The observation template is optional and blank. If an instructor later records a session, distinguish observed actions from interpretations, note assistance and build identity, and follow the institution's rules for student information. This package records no completed sessions or named learners.
