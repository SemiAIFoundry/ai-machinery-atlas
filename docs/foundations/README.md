# Mathematical and algorithmic foundations

Ten inspectable mechanisms support the route from science to model learning: indexed matrix products, a rank-one map, stable probabilities and gradients, a miniature binary format, finite sampling, confounding, annotation disagreement, fitted stumps, graph propagation and minimax search. Every control changes an actual array, arithmetic operation or declared decision rule.

The rank specimen constructs a two-dimensional symmetric map with chosen singular values and rotates its orthogonal directions. The seven-bit E3M3 format is original teaching arithmetic with ties-to-even; it is not a claim about an IEEE or vendor format. Sampling uses an exact binomial distribution. The confounding fixture has authored structural rules, so observing its causal contrast is different from identifying effects in observational real-world data. Adjudication changes a declared label policy and does not establish ground truth.

Stumps fit squared-error residuals on six authored examples. They demonstrate additive fitting without implementing XGBoost's regularization, second-order objective, sparse storage or distributed system. The four-node graph uses self-loops, symmetric degree normalization and ReLU with an identity feature map; weights are not trained. Minimax searches a finite tic-tac-toe rule system with an authored depth-limit heuristic. It is not AlphaZero or a learned value function.
