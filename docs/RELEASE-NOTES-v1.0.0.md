# AI Machinery Atlas v1.0.0

First portable reference edition, September 2026. The atlas connects the physical and computational machinery behind AI through 97 lessons, 26 procedural 3D branches, five learning paths, seven numerical labs, and 41 historical milestones. The Ascent companion film is included with locally hosted scripts and generated narration.

Original source and educational material are released under MIT. Third-party licenses, font notices, citations, and the narration credit are retained. The platform can be built as a static site without a backend, API key, or Sites account.

Validation: TypeScript and the production build; curriculum and scene coverage across all 97 lessons; numerical invariants; root and subdirectory asset resolution; film script parsing; and exact license-text checksums. These checks do not constitute browser UI or accessibility certification.

Artifacts: `ai-machinery-atlas-v1.0.0-source.zip`, `ai-machinery-atlas-v1.0.0-static.zip`, and `SHA256SUMS.txt`. The static archive contains `index.html` at its root. Scientific geometry and labs are explanatory; the atlas does not disclose Astra's private architecture or establish an AGI date.
