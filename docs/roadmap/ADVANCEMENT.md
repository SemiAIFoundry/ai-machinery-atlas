## Additive breadth

The user reaffirmed that the roadmap is a minimum scope, not a breadth limit. Four further worked lessons connect sharded tensor ownership, sample-weighted distributed gradients, binary32 reduction order and corrected speculative sampling. They add eight canonical equations and one guided path. Architecture and application experiences link to these mechanisms without implying their existing simulators execute distributed collectives or speculative decoding.

## Verification and provenance

The [current validation record](ADVANCEMENT-VALIDATION.md) identifies the coordinated build, automated suites, actual browser tasks and capture used for the navigation companion. Source checks name the actor and scope; a working URL alone is never described as verification. Existing public product specifications remain distinct from synthetic inputs, derived results, hypothetical cost scenarios and physical observations.

The instructor contracts can be run without a browser or account. The hardware artifact can be inspected from its checked-in logs and hashes without installing EDA tools; reproducing the native flow uses its recorded public tool versions. The FPGA bitstream is an artifact of this example, not a board-qualified binary or foundry layout.
